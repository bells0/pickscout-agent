# 0012：商业判断优先的首要选品原则

- 状态：accepted
- 日期：2026-09-17
- 用户决定：明确要求将已认可的选品要点写入 Agent，作为以后必须遵守的首要原则。
- 后续补充：[0015](0015-judgment-and-user-controlled-collaboration.md)明确数据之上的专业判断、按试错风险确定证据强度及用户控制协作，防止本原则仍被解释为未知清零。

## 背景

选品研究曾把竞品的具体结构误当成候选准入条件，并在初筛阶段追索不会改变当前经营判断的后续验证细节。这使证据要求偏离发现商业机会与支持用户判断的目标。

## 决策

以 [方法论第 1.1 节](../pickscout-methodology-v1.md#11-首要选品原则) 为完整规则，在根目录 Agent 契约及分发技能入口保留必读摘要：

- 围绕需求、竞争与进入空间、经济与供给、用户选择四个商业问题研究。
- 竞品属性只作比较；不默认要求完全同款、固定结构、创新或定制。功能合适的现货和替代形态均可评估。
- 按阶段投入精力，只补可能改变可行性、优先级或投入的信息；非关键细节不阻塞推进。
- 资料未齐可提供注明限制的初步选项和建议，不冒充严格排名、最终通过或交易就绪结论。
- 比较多个产品与供应商，整合证据并提建议，用户保留最终经营决定。
- 硬门槛须有用户约束或当前阶段实际风险依据；证据真实性、可复算计算及外部动作独立授权继续保留。

这些原则优先约束 SOP、协议和模板的解释；用户当前明确指令优先。此决定改变研究方法，不批准任何具体候选、买样、采购或外部发布。

## 备选方案与影响

仅留在对话或单次任务记录不足以约束以后研究，因此不采用。也不采用删除所有证据要求的做法，以免把估算当成事实或把研究推进误当作交易授权。

同步更新 PRD、Agent 入口、方法论、SOP、研究协议及仓库内分发适配器。使用已有分发一致性与研究契约检查验证文档接入，不新增评分门槛、审批层或逐字匹配测试。后续用实际研究检验是否仍发生无关细节阻塞，并按此原则纠正。
