# 0011：一个选品专员负责完整流程

- 状态：accepted
- 日期：2026-09-10
- 取代：0010 多角色方案
- 后续调整：2026-10-30，[0015](0015-judgment-and-user-controlled-collaboration.md)保留单一负责人，但复杂探索改为用户控制的按需多 Agent 分工；下述单 Agent 默认为当时决定，不再一刀切适用。

## 决策

当前阶段由一个选品专员负责完整选品流程，复用当前任务和主项目目录。市场、供应、利润及风险是同一负责人需要覆盖的研究维度，不分别建立常驻岗位。

原三个成员退休并归档；历史报告和交接保留，不删除 worktree。后续不默认调用额外 Agent，确有持续瓶颈再由用户确认调整。

## 理由与验证

当前只有组队接入检查，没有真实并行研究负载。多成员带来的重复上下文和交接成本缺少实际收益支撑。单一负责人更符合现阶段的连续研究与综合判断需要。

核对当前任务名称、单一活跃角色与旧成员归档，以及文档不再指导多角色派发。真实流程按后续候选验证；角色方案确认不等于样品、采购或发布授权。
