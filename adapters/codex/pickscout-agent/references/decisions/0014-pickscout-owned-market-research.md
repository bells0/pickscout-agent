# 0014：PickScout 统一维护市场研究与八步方法

- 状态：accepted
- 日期：2026-10-29
- 取代：0013 的外仓单源、PickScout 只读接入；澄清 0002/0008 的产品核心、项目 Skill 和完整 Agent 适配器边界。

## 背景与用户决定

用户确认采用可复用的 Amazon US 市场研究方案，要求研究方法、Skill 和产出以 PickScout 为主项目。旧规则把研究 Skill 维护在运营项目，且部分充分性条款把完整成本提前要求于市场研究，会造成归属和阶段混淆。本次按已取得的引用会话正文吸收方法；引用中的附件未经取得前不作为已读资料。私人来源、用户身份和案例数据不进入公共方法。

## 决定

1. PickScout 维护选品、品类、竞品、需求、趋势与市场研究方法和产物。auto-amazon 聚焦 Listing、Seller Central、FBA、库存、订单和运营执行；研究结论与经营采纳、外部授权、执行回执分开。
2. 本仓 `skills/amazon-category-opportunity-research/` 是该 Skill 唯一活跃维护源，`.agents/skills/` 仅为本地发现链接，不全局安装。auto-amazon 的旧源和入口由其原负责人后续清理/改为引用；本轮不改外仓，也不长期维持双主源。
3. 详细方法统一在 `docs/market-research-v1.md`：A/B 研究内环八步、六维判断、九章主报告；完整 A–G 外环、确定性工具与决定记录继续有效。适配器镜像同一规范与模板，不另维护研究方法正文。
4. 市场阶段优先卖家精灵，表格/截图均可；不先要求现有工厂、供应商、样品或完整成本。经济性独立标记未评估/情景/有来源计算；成本缺口不阻塞有依据的市场结论，也不允许宣称盈利。
5. 保留完整自然月、父子体、可见新品选择偏差、同规格评论与价格边界；逐维支持、反证与条件代替自动总分、固定利润或评论数门槛。取样窗口是可说明调整的设置，不是成功模型。
6. 默认本地 HTML 主报告，按用户要求交付 Excel/PDF 等；不为方法固化启动新研究、重抓全市场、配置服务、付费或公开发布。
7. 历史研究按原件、目标、版本和本地依赖列清单；本轮只固化方法资产，不搬大导出/原图或批量删除。后续迁移由对应负责人执行并确认恢复路径。

## 验证与未完成

检查现有分发包镜像、研究契约、文档路径和 Skill 格式；用既有研究档案对照覆盖问题，不把对照称为新研究验收。状态只到“结构/已有案例对照已检查；新真实研究调用尚未验证”。Git 交付由对应已绑定角色负责，本轮不暂存、提交、推送、PR 或合并。
